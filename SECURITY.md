# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately to the maintainer on Telegram:
[@diementros](https://t.me/diementros).

Do not disclose vulnerabilities in public GitHub issues or pull requests before
a fix is available and disclosure has been coordinated with the maintainer.

Include the following details when possible:

- The affected version or commit.
- A description of the vulnerability and its potential impact.
- Steps to reproduce it, or a minimal proof of concept.

Remove tokens, credentials, and private chat data from reports and examples.

## Supported versions

Security fixes are provided for the latest code on the default branch. Older
versions do not receive separate security updates.
